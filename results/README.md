# Results

- `training_metrics.json` contains the metrics from a successful repository-level retraining check.
- `validated_hybrid_rollouts/` contains rollout CSVs from the previously validated hybrid simulation build.
- `rollouts/` is created automatically by the learned-policy and hybrid-policy runtime scripts when new tests are run.
- `media/` is reserved for final real-robot and Panda demonstration media.

Final aggregate success-rate tables can be added here after the target-machine validation run.
